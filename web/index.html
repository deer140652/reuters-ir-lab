01資料集與實驗設計

Reuters-21578 依 ModApte 切分：詞向量只用訓練集學習，檢索在另外的測試集上進行。新聞屬於哪些主題由 topics 欄位標示，用來判斷一篇新聞是否相關。

文件表示方法

A　TF-IDF w(t,d) = (1 + ln tf) × ln(N / df) 分數 = cos(q, d) B　TF-IDF 加權詞向量 d = Σ w(t,d) · v̂_t　　（v̂_t：單位長度的詞向量） q = Σ w(t,q) · v̂_t 分數 = cos(q, d)

B 保留 TF-IDF 對「重要的詞」的判斷，再用詞向量帶入詞的上下文。兩者使用同一套前處理：轉小寫、去標點與數字、去停用詞，不做詞幹還原。

03詞向量的語意鄰近分析

詞向量依上下文的相似程度排列詞彙。在路透社語料中，最近鄰多半反映新聞情境的共現關係，例如固定搭配、同一事件的人物與公司，甚至是反義詞，而不一定是同義詞。這些鄰近關係是否真的影響排序，見第 04、05 節。
